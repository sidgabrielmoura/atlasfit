## Triagem com fontes do mantenedor

- Next 16.2.6 está no intervalo afetado pelo aviso de DoS em App Router com Server Actions. Há Server Actions no projeto. [Aviso Vercel](https://github.com/vercel/next.js/security/advisories/GHSA-m99w-x7hq-7vfj).
- Há também aviso crítico para servidor hospedado em filesystem Windows. O workspace local é Windows; isso não identifica o sistema operacional da hospedagem de produção. [Aviso Vercel](https://github.com/vercel/next.js/security/advisories/GHSA-p293-qw3h-jr36).

O problema de normalização de email exige provider passwordless; o projeto usa Credentials, portanto não foi demonstrado por esse caminho. [Aviso Auth.js](https://github.com/nextauthjs/next-auth/security/advisories/GHSA-7rqj-j65f-68wh).
- O aviso de erro de configuração com auth truthy tem mitigação relevante no checkout: os guards verificam session.user.id e o middleware verifica auth.user. Não foi reproduzido bypass de login decorrente desse aviso. [Aviso Auth.js](https://github.com/nextauthjs/next-auth/security/advisories/GHSA-8fpg-xm3f-6cx3).
